**List<T>** — это последовательная коллекция элементов под управлением .NET, представляющая собой высокоуровневую обёртку над стандартным массивом фиксированной длины `T[]`.

---

## ⚙️ Механика работы под капотом

* **Базовая структура:** Внутри скрыт обычный массив `T[]`.
* **`Count`** — фактическое количество элементов, добавленных в список на данный момент.
* **`Capacity`** — текущая емкость (размер) внутреннего массива в памяти.
* **Алгоритм расширения:** По умолчанию начальная емкость равна `0` (выделяется при первом добавлении, обычно сразу `4`). Как только `Count == Capacity`, внутренний массив заполняется. `List<T>` автоматически создаёт в куче новый массив, который **в 2 раза больше предыдущего** (`4 → 8 → 16 → 32 → ...`), и копирует туда все старые элементы через `Array.Copy`.

---

## 📊 Операции и их временная сложность (Сложность для собеседований)

| Операция | Сложность | Описание / Механика |
| :--- | :--- | :--- |
| **`list[индекс]`** | **O(1)** | Доступ или изменение по индексу. Прямое обращение к ячейке памяти. |
| **`Add()`** | **O(1)** (в среднем) | Добавление элемента в конец списка. Если `Count == Capacity`, происходит перевыделение памяти и операция временно превращается в **O(n)**. |
| **`Insert()`** | **O(n)** | Вставка элемента в середину или начало. Требует сдвига всех последующих элементов в памяти вправо. |
| **`Remove()`** | **O(n)** | Удаление элемента по значению или индексу. Требует сдвига всех элементов после удаленного влево, чтобы не было «дыр». |
| **`Contains()` / `IndexOf()`** | **O(n)** | Линейный поиск элемента. В худшем случае обходит весь массив с начала до конца. |

### 💡 Оптимизация памяти (Best Practice)

```csharp
// 🛑 ПЛОХО: Вызовет цепочку пересозданий внутреннего массива и лишнюю нагрузку на GC (Garbage Collector)
var list = new List<int>(); 
for (int i = 0; i < 100_000; i++) list.Add(i);

//  ОТЛИЧНО: Задаем Capacity сразу, выделяя один массив в памяти под нужный объем данных
var optimizedList = new List<int>(capacity: 100_000);
for (int i = 0; i < 100_000; i++) optimizedList.Add(i);
