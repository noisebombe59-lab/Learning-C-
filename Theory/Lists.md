List<T> (Динамический массив)
Обёртка над обычным фиксированным массивом T[]. Когда внутренний массив заполняется, List<T> автоматически создаёт в куче новый массив большего размера и копирует туда все данные.

Механика работы под капотом

База: Обёртка над обычным массивом T[].
Count — реальное количество элементов в списке.
Capacity — размер внутреннего массива. По умолчанию начинается с 4 и удваивается при заполнении (4 → 8 → 16 → 32 → ...).
O(1) — операции, которые выполняются мгновенно (время не зависит от размера списка).
O(n) — операции, скорость которых зависит от количества элементов.


Операции и их сложность (Критично для собеседований)

list[индекс] (доступ / изменение) — O(1): Прямое обращение к ячейке памяти.
Add() (добавление в конец) — O(1) в среднем.
Исключение: Если Count == Capacity, то происходит расширение массива — операция становится O(n).
Insert() / Remove() (вставка или удаление в середине) — O(n): Нужно сдвигать все элементы после изменяемого места.

C#// ПЛОХО: будет много пересозданий массива
var list = new List<int>();

// ОТЛИЧНО: задаём Capacity сразу
var optimizedList = new List<int>(capacity: 100_000);

Правила удаления элементов
Критическая ошибка (вызовет InvalidOperationException):
C#// ОШИБКА! Нельзя изменять коллекцию во время foreach
foreach (var item in fruits)
{
    if (item == "banana") 
        fruits.Remove(item);
}
Правильный подход:
C#// Быстро и безопасно
fruits.RemoveAll(f => f == "banana");
