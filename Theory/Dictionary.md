# Dictionary<TKey, TValue> в C#

Коллекция пар «ключ — значение». Обеспечивает практически мгновенный поиск, добавление и удаление элементов по ключу за константное время $O(1)$ в среднем. Под капотом использует структуру данных **Хеш-таблица**.

## Подключение пространства имен

```csharp
using System.Collections.Generic; // Основное пространство имен для коллекции
using System.Linq;                // Для методов расширения (ToDictionary)
```

---

## Создание и инициализация

```csharp
// 1. Пустой словарь (явное указание типов)
Dictionary<string, int> ages = new();

// 2. Инициализатор индексатора (Рекомендуемый современный стиль)
var capitals = new Dictionary<string, string>
{
    ["Франция"] = "Париж",
    ["Германия"] = "Берлин"
};

// 3. Классический инициализатор коллекции
var scores = new Dictionary<string, int>
{
    { "Анна", 95 },
    { "Борис", 88 }
};
```

---

## Добавление и изменение значений

```csharp
var ages = new Dictionary<string, int>();

// Индексатор: добавляет новую пару или перезаписывает значение, если ключ существует
ages["Виктор"] = 22; 

// Метод Add(): бросает ArgumentException, если ключ уже присутствует в словаре
ages.Add("Дарья", 28); 

// Метод TryAdd(): добавляет элемент только при отсутствии ключа. Возвращает bool, не генерирует исключений
bool isAdded = ages.TryAdd("Анна", 26); 
```

---

## Безопасное чтение данных

```csharp
// 1. Прямое обращение по индексу (Допустимо ТОЛЬКО при полной уверенности в наличии ключа)
int annaAge = ages["Анна"]; // Бросает KeyNotFoundException, если ключа нет

// 2. Метод TryGetValue() — наиболее эффективный способ (один хэш-поиск вместо двух)
if (ages.TryGetValue("Анна", out int age))
{
    Console.WriteLine($"Анне {age} лет");
}

// 3. Метод GetValueOrDefault() — возвращает значение ключа либо дефолт (0, null и т.д.)
int score = scores.GetValueOrDefault("Виктор", 0);
```

---

## Удаление элементов и проверка наличия

```csharp
// Удаление по ключу. Возвращает true, если элемент успешно удален
bool isRemoved = ages.Remove("Борис"); 

// Проверка существования ключа (Сложность O(1))
bool hasKey = ages.ContainsKey("Анна"); 

// Проверка существования значения (Внимание: Сложность O(N) — полный перебор!)
bool hasValue = ages.ContainsValue(25); 

// Свойства и полная очистка
int count = ages.Count; 
ages.Clear(); 
```

## Итерация (Перебор элементов)

```csharp
// 1. Через структуру KeyValuePair<TKey, TValue>
foreach (KeyValuePair<string, int> pair in ages)
{
    Console.WriteLine($"{pair.Key} → {pair.Value}");
}

// 2. Использование деконструкции кортежей (C# 7+)
foreach (var (name, age) in ages)
{
    Console.WriteLine($"{name} — {age} лет");
}

// 3. Перебор только ключей или только значений (.Keys и .Values оптимизированы)
foreach (string key in ages.Keys) { /* ... */ }
foreach (int value in ages.Values) { /* ... */ }
```

## Полезные LINQ-методы преобразования

```csharp
// Преобразование коллекции объектов в словарь (Id должен быть уникальным, иначе — ArgumentException)
Dictionary<int, User> uniqueUsers = users.ToDictionary(u => u.Id, u => u);

// Группировка данных с последующим приведением к словарю списков
Dictionary<string, List<User>> byCountry = users
    .GroupBy(u => u.Country)
    .ToDictionary(g => g.Key, g => g.ToList());
```

## Важные технические правила и ограничения

* **Управление исключениями:** Прямой вызов `dict["invalid_key"]` приводит к `KeyNotFoundException`. Передача `null` в качестве ключа во все методы (включая индексатор) приводит к `ArgumentNullException`.
* **Уникальность и HashCode:** Ключ идентифицируется комбинацией методов `GetHashCode()` и `Equals()`. Поведение словаря напрямую зависит от корректности реализации этих методов у типа ключа.
* **Неизменяемость ключей:** В качестве ключей следует использовать иммутабельные типы (`string`, `int`, `record`, `ValueTuple`). Изменение внутреннего состояния объекта-ключа после его добавления в словарь разрушает хэш-таблицу (элемент станет невозможно найти).
* **Порядок элементов:** `Dictionary<TKey, TValue>` не гарантирует и не сохраняет порядок вставки элементов при их удалении или изменении.
* **Альтернативы:**
  * Если требуется постоянная сортировка по ключам — используйте `SortedDictionary<TKey, TValue>` (сложность операций $O(\log N)$, реализован на основе Красно-черного дерева).
  * Если важен порядок вставки — используйте `OrderedDictionary` (из пространства `System.Collections.Specialized`).
