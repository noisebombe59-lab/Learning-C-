Группа 1: База данных и Entity Framework Core (Работа с SQL)

    Microsoft.EntityFrameworkCore.SqlServer

Для чего: Это драйвер (провайдер) базы данных. Он переводит твои C#-модели и LINQ-запросы на язык, который понимает Microsoft SQL Server.

    Microsoft.EntityFrameworkCore.Design

Для чего: Инструмент для сборки миграций. Он нужен самой среде разработки (IDE), чтобы она могла генерировать файлы миграций в проекте через терминал.

    Microsoft.EntityFrameworkCore.Tools

Для чего: Добавляет поддержку команд миграций (Add-Migration, Update-Database) в специальное окошко Visual Studio — Package Manager Console (Консоль диспетчера пакетов).

Группа 2: Аутентификация и защита (JWT и Безопасность)

    Microsoft.AspNetCore.Authentication.JwtBearer

Для чего: Учит твое API проверять «цифровые пропуска» клиентов. Он перехватывает входящие запросы в Program.cs и проверяет JWT-токен на валидность (сверяет секретный ключ, сроки, издателя).

    Microsoft.AspNetCore.Identity.EntityFrameworkCore

Для чего: Мост между движком пользователей (Identity) и базой данных. Перестраивает твой контекст БД, чтобы автоматически создать 7 системных таблиц (для пользователей, ролей, хэшей паролей).

    Microsoft.Extensions.Identity.Core

Для чего: «Мозги» системы пользователей. Содержит базовую логику классов UserManager и RoleManager, правила проверки сложности паролей и алгоритмы их хэширования.

Группа 3: JSON и Форматирование данных (Лечение ошибок)

    Microsoft.AspNetCore.Mvc.NewtonsoftJson

Для чего: Решает проблему циклических ссылок в JSON. Когда Акция ссылается на Комментарий, а Комментарий обратно на Акцию, стандартный .NET-парсер уходит в бесконечный цикл и ломается. Этот пакет заменяет его на классический Newtonsoft.Json, который умеет такие циклы красиво игнорировать.

Группа 4: Swagger и Документация (Визуальное тестирование)
Swashbuckle.AspNetCore

Для чего: Генерирует саму интерактивную веб-страницу Swagger в браузере, где ты можешь видеть список всех своих контроллеров, нажимать кнопки и отправлять JSON-запросы без использования Postman.

Microsoft.AspNetCore.OpenApi

Для чего: Поставляет метаданные и аннотации для маршрутов твоего API, чтобы Swagger точно знал, какие типы данных (DTO) принимает и возвращает каждый твой метод.
