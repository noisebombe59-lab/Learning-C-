1. Суть паттерна
Это слой-прослойка между твоим контроллером (бизнес-логикой) и базой данных.

Контроллер больше не должен знать, как устроена база и откуда берутся данные. Он просто делает запрос к репозиторию: «Дай мне список акций», а репозиторий сам разбирается со спецификой SQL-запросов, LINQ и Entity Framework Core.

2. Главные преимущества внедрения
Чистота кода: Контроллеры избавляются от тяжелых LINQ-запросов, методов Include() для подгрузки связей и становятся маленькими, сфокусированными только на обработке HTTP-статусов.

Изоляция для тестирования (Тесты): Позволяет легко подменить реальную базу данных на «фейковый» (Mock) репозиторий в оперативной памяти, чтобы протестировать поведение контроллера без подключения к SQL Server.

Заменяемость технологий: Если в будущем потребуется поменять релизационную базу данных SQL Server на нереляционную MongoDB, тебе придется переписать только код внутри репозиториев. Код самих контроллеров останется абсолютно нетронутым.
