Два рубежа обороны APIПростая проверка (в URL): Маршрутизация отсекает неверные типы данных на подлёте.Комплексная проверка (в JSON): Атрибуты проверяют внутренности присланных объектов.Рубеж №1: Валидация маршрута (Route Constraints)Это жесткий фильтр прямо в строке URL. Ограничение по типу данных дописывается в шаблоне маршрута через двоеточие (:int).

    C#
    [HttpGet("{id:int}")] // Говорим роутингу: "Принимай только цифры!"
     public async Task<IActionResult> GetById([FromRoute] int id) 
     {
         var stock = await _repository.GetByIdAsync(id);
         if (stock == null) return NotFound();
         return Ok(stock.ToStockDto());
     }
  
Как это работает под капотом:Клиент шлет GET api/stock/5 $\rightarrow$ Роутинг видит число $\rightarrow$ Передает управление методу контроллера.Клиент шлет GET api/stock/abc $\rightarrow$ Роутинг видит строку, понимает, что данный маршрут не подходит $\rightarrow$ Сразу возвращает 404 Not Found.Итог: Контроллер вообще не запускается и не тратит ресурсы процессора на попытку распарсить строку "abc" в число.Рубеж №2: Комплексная валидация JSON (Data Annotations)Для проверки структуры и содержимого тяжелых объектов используются специальные атрибуты (аннотации) над свойствами классов.⚠️ Техническое ограничение: Никогда не ставь атрибуты валидации в доменные модели (классы сущностей БД). Они должны жить строго внутри DTO (CreateStockDto, UpdateCommentRequestDto). Правила ввода данных на фронтенде постоянно меняются, и эти изменения не должны влиять на архитектуру базы данных.Основные инструменты (Data Annotations)[Required] — Поле обязательно для заполнения (не может быть null или пустым).[MinLength(x)] / [MaxLength(x)] — Ограничение минимальной и максимальной длины строк.[Range(min, max)] — Ограничение допустимых числовых диапазонов.

    C#
    public class CreateCommentRequestDto
    {
        [Required]
        [MinLength(5, ErrorMessage = "Title must be 5 characters")]
        [MaxLength(280, ErrorMessage = "Title cannot be over 280 characters")]
        public string Title { get; set; } = string.Empty;
    
        [Required]
        public string Content { get; set; } = string.Empty;
    }
