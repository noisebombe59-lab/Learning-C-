Теория: EF Core использует «ленивую загрузку» по умолчанию — он не тянет связанные данные, пока не попросишь. Метод .Include() заставляет EF Core сгенерировать SQL-запрос с оператором JOIN, чтобы склеить таблицы и достать всё за один раз.

C#
// Репозиторий / Контроллер
public async Task<List<Stock>> GetAllAsync() {
    return await _context.Stocks
        .Include(s => s.Comments) // Команда базе: "Приклей комментарии к акциям через JOIN"
        .ToListAsync();           // Без .Include() список Comments будет всегда пуст ([])
}
Нюанс: Не «инклюдь» всё подряд. Каждый JOIN увеличивает количество данных в ответе базы (дублирует строки родителя для каждого ребенка), что нагружает сеть.
