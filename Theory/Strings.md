    Strings и StringBuilder
Коротко: string — это неизменяемый текст (каждое изменение создает новый объект), а StringBuilder — это динамический буфер, который редактирует текст внутри себя без создания мусора.

    String (Строка)
Ссылка на объект в куче, но ведет себя предсказуемо благодаря неизменяемости (immutable).

Каждое изменение (+, Replace, ToLower) оставляет старую строку в памяти нетронутой и создает в куче абсолютно новую строку.

C#
string a = "hello";
a += " world"; // В куче создалась третья строка "hello world". 
               // Строки "hello" и " world" остались лежать в памяти как мусор.
Шпаргалка к терминам:

Иммутабельность (Immutable): Запрет на изменение объекта после его создания. Нельзя заменить символ внутри строки, можно только пересоздать строку целиком.

Потокобезопасность строк: Поскольку строку нельзя изменить, несколько потоков выполнения могут одновременно читать её и не бояться, что другой поток в этот момент её испортит.

    StringBuilder
Изменяемый (mutable) класс-помощник.

Как работает: Выделяет в куче один массив символов (буфер) и при операциях (Append, Insert) заполняет его. Объект в памяти остается один и тот же.

    C#
    var sb = new StringBuilder();
    sb.Append("hello");
    sb.Append(" world"); // Данные просто дописались в тот же самый массив в памяти.
Шпаргалка к терминам:

Аллокация: Выделение нового куска памяти в куче под объект. string += делает аллокацию при каждом шаге, StringBuilder — только когда его внутренний массив полностью забивается.

Начальная емкость (Capacity): Размер внутреннего массива символов. Если заранее задать new StringBuilder(10_000), то массив сразу займет нужное место и программа не потратит время на его расширение в процессе работы.

Когда что использовать
Используй string:
Для 1–5 простых склеек (компилятор сам оптимизирует их через string.Concat).

Для констант, путей, URL, токенов.

Используй StringBuilder:
СТРОГО в любых циклах, где идет сборка текста.

Для генерации больших объемов данных (логи, HTML, CSV).

Когда над одной строкой выполняется больше 10 последовательных манипуляций.

Шпаргалка по методам для собеседования
Эффективные методы string:
string.IsNullOrWhiteSpace(str) — лучший способ проверки. Возвращает true, если строка пустая, равна null или состоит только из пробелов.

string.Join(", ", array) — быстро собирает массив в одну строку через разделитель (внутри сам использует StringBuilder).

str.Split(';') — режет строку в массив по указанному символу.

Эффективные методы StringBuilder:
sb.AppendLine("текст") — добавляет текст и автоматически переносит строку (\r\n).

sb.Clear() или sb.Length = 0 — мгновенно обнуляет буфер для повторного использования, чтобы не создавать новый StringBuilder.

sb.ToString() — вызывается строго один раз в самом конце, чтобы забрать готовый текст.

Паттерн «Плохо против Хорошо»
Критическая ошибка (тысячи аллокаций мусора в куче):

     C#
     string log = "";
     for (int i = 0; i < 10_000; i++)
     {
         log += $"действие {i}\n"; // Худший код для памяти: создаст 10 000 временных строк
     }
     
Профессиональный подход (одна аллокация, ноль нагрузки на GC):

      C#
      var sb = new StringBuilder(1_000_000); // Задали Capacity заранее
      for (int i = 0; i < 10_000; i++)
      {
          sb.Append("действие ").Append(i).AppendLine(); // Сборка в один буфер
      }
      string finalLog = sb.ToString(); // Вызов только в конце
